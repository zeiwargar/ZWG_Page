Desarrollo de Aplicaciones Multiplataforma

Sobre mí

Actualmente estoy estudiando Desarrollo de Aplicaciones Multiplataforma (DAM), un Ciclo Formativo de Grado Superior.

En mis estudios trato con lenguajes de programación orientada a objetos como Java y lenguajes de marcas como HTML, CSS, JavaScript, JSON. También lenguajes SQL como PostgreSQL y SQLite orientados a Bases de Datos.

En cuanto a Entornos de Desarrollo he trabajado con IntelliJ y WebStorm usando frameworks como Picnic, Bootstrap y Alpine, enlazando las Bases de Datos con las páginas HTML mediante Node.js.

Proyectos

Creación de una API

Usando los conocimientos de varios de los módulos del curso combinados, he creado una pagina web que muestra datos combinados de diversas tablas de una Base de Datos, permitiendo navegar, añadir, borrar y modificar los mismos.

e-Comerce

Desarrollada enteramente en Java, he podido crear una aplicacion capaz de gestionar la compra y la venta de productos entre diferentes usuarios.

Casos de Pruebas

Con el conocimiento adquirido durante el curso, he diseñado y experimentado con diversos casos de prueba de caja blanca y caja negra. Las pruebas unitarias son esenciales para el diseño de aplicaciones.
